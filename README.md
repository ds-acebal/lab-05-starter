# Lab 5: Graphical Editor with Undo/Redo

In this assignment, you will extend the graphical editor developed in Lab 3 by adding **undo/redo functionality**.

> [!NOTE]
> The starter code is based on our reference solution for Lab 3.
> However, you are welcome to continue working on your own Lab 3 implementation instead.
> If you choose to do so, copy your code into your Lab 5 repository, keeping its `.git` directory intact.

## Additional Resources

The `extras/` folder contains a runnable JAR file with undo/redo functionality, which you can use to test your implementation. You can run it with the following command:

```bash
java -jar extras/editor-with-undo.jar
```

## Submitting the Assignment

Your work must be committed and pushed to your Classroom50 repository before the next lab session.

When you have finished, run:

```bash
git add -A
git commit -m "Final submission"
git push
```
